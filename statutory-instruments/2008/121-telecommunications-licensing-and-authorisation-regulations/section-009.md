PART V
CLASS LICENCE
Application for class licence
9. An application for a class licence shall be for either a class
licence Type A Service or class licence Type B Service and shall be
submitted to the Commission —
(a) in the prescribed form and contain such information and
particulars as are set out in the Fifth and Sixth Schedules
respectively; and
(b) be accompanied by the prescribed application fee which shall
be non-refundable.
Consultations on class licence application.
