96.
E-Cash
In concept electronic cash or e-cash would replace the need for notes and
coins for transactions carried out via the internet.  With e-cash value is
purchased from an authorized provider, similar to what obtains for the
smartcard.  The value is then stored to either a safe repository on-line or to
the customer’s home computer.  When the e-cash is spent the
corresponding value is then credited to a retailer’s e-cash account which is
later followed by the deposit to the retailer’s regular bank account.  The
security of the e-cash system is mainly concerned with ensuring that value
cannot be created by unauthorized institutions or that the value cannot be
spent more than once.
