Procedure in indictable cases generally
852. The provisions of this Code or any other enactment, regulating
any criminal proceedings in cases or matters not indictable, shall apply if
necessary, to all proceedings in indictable cases, where there is no ex-

press provision in this Code or any other enactment applicable to such
indictable proceeding, except where it appears from the context that
such provision is not applicable to indictable cases.
